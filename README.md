# ScholarSphere

![ScholarSphere Logo](assets/images/icon.png) <!-- Replace with your logo image path -->

**ScholarSphere** is an all-in-one platform designed for students and educators to create, manage, and interact with academic materials seamlessly. Whether you're organizing your study notes, generating flashcards, managing your todo list, recording lectures, or providing feedback, ScholarSphere provides intuitive tools to enhance your academic journey.

---

## 🛠️ Features

- **User Authentication**
  - Secure sign-in and sign-out using JWT (JSON Web Tokens).

- **Todo List**
  - Add, delete, and mark tasks as completed.
  - Persistent storage using AsyncStorage.
  - Engaging confetti animation and vibration feedback upon task completion.

- **Document Uploader**
  - Upload PDF documents.
  - Background processing of uploaded files.
  - Secure file handling with JWT authentication.

- **Lecture Recording**
  - Record audio lectures directly within the app.
  - Preview and upload recorded lectures.
  - Secure upload to backend server.

- **Feedback Page**
  - Submit feedback or suggestions.
  - Secure communication with backend using JWT.

- **Chat Area**
  - Interact with a personal AI assistant to generate flashcards, multiple-choice questions, and more.

- **Theming**
  - Support for Light and Dark modes.

- **Responsive Design**
  - Optimized for both iOS and Android devices.

## 📦 Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/np123/ScholarSphere.git
    cd ScholarSphere
    ```

2. Install dependencies:
    ```sh
    npm install
    ```

3. Start the development server:
    ```sh
    npx expo start
    ```
